# MoviCibao-Web

MoviCibao-Web es una plataforma web colaborativa orientada a facilitar la movilidad en la Región Cibao Norte. Permite a los usuarios consultar las rutas de transporte y comparar las alternativas disponibles para elegir la que mejor se adapte a sus necesidades de desplazamiento.

Además, permite reportar incidencias relacionadas con el transporte. Con este enfoque colaborativo, la plataforma busca que los propios usuarios aporten información útil para la comunidad y ayuden a otras personas a planificar mejor sus viajes.
